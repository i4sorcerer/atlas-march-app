# 猎鹰9号科普网站 - SPEC.md

## 1. Concept & Vision

一个为5岁小朋友设计的猎鹰9号（Falcon 9）火箭科普交互网站。整体感觉像一本超大的立体书+玩具盒，带小朋友一起探索太空火箭的奥秘。用温暖可爱的画风、简单的语言、丰富的动画，让小朋友觉得"太空真好玩！"。每个部分都可以点一点、玩一玩，学到东西同时享受探索的乐趣。

## 2. Design Language

### 色彩系统
- 主色：深空蓝 `#0D1B2A` (背景底色，模拟太空)
- 次要色：星光金 `#FFD166` (高亮、文字强调)
- 点缀色：火箭红 `#EF476F` (按钮、重要交互)
- 辅助色：星光白 `#E8F1FF` (文字、边框)
- 渐变背景：深空紫 `#1B0033` → 深空蓝 `#0D1B2A`
- 辅助亮色：科技蓝 `#06D6A0` (成功状态、动画高亮)

### 字体
- 标题字体：Nunito（圆润可爱，适合儿童）
- 正文字体：ZCOOL KuaiLe（中文圆润风格）
- 数字/英文强调：Fredoka One

### 空间系统
- 圆角为主：border-radius 16px~32px
- 大块留白，呼吸感强
- 卡片式布局，圆润柔和

### 动效哲学
- 所有动画弹性、弹性感强（ease-in-out + bounce）
- 星星闪烁漂浮动画（CSS keyframes）
- 点击有"弹弹"反馈感
- 页面滚动触发动画（IntersectionObserver）
- 火箭各部分可点击展开爆炸图

### 视觉元素
- 图标：Emoji + 自定义SVG图标（火箭、星星、宇航员等）
- 装饰：漂浮星星、轨道线条、行星
- 使用Canvas绘制星空背景

## 3. Layout & Structure

### 页面结构
1. **Hero区** - 全屏深空背景，漂浮星星，火箭从下方升起动画，中央大标题，滚动引导
2. **什么是猎鹰9号** - 简单介绍卡片，适合5岁理解
3. **火箭大拆解** - 可交互的火箭爆炸图，点击各部分展开详情
4. **发射动画模拟** - 完整发射流程动画（倒计时→发射→分离→着陆）
5. **火箭有多厉害** - 数据展示卡片（高度、重量、速度等）
6. **小问答** - 互动小测验（3-4个简单问题）
7. **尾声** - 鼓励小朋友，宇航员梦想

### 响应式
- 移动端优先，卡片纵向堆叠
- 平板横屏优化
- 桌面端宽屏展示

## 4. Features & Interactions

### Hero区
- Canvas星空背景，星星随机闪烁
- 火箭SVG从下方缓慢飞入
- 标题文字逐字出现
- 向下滚动箭头跳动动画

### 火箭拆解（核心功能）
- 展示完整火箭（SVG）
- 点击"拆开看看"按钮，火箭各部分爆炸散开
- 每个部分悬停显示简介标签
- 点击具体部分弹出详情卡片（动画滑入）
- 包含：一级助推器、二级助推器、有效载荷整流罩、引擎、燃料箱
- "组装回去"按钮恢复原状

### 发射模拟动画
- 倒计时：10→9→8...→发射（数字放大动画）
- 发射：火焰粒子效果，火箭上升
- 一级分离：助推器飘落
- 着陆：栅格翼展开，垂直下落，落地缓冲

### 数据展示
- 数字计数动画（数字滚动到目标值）
- 对比图（猎鹰9号 vs 其他物体大小）

### 小问答
- 3道选择题，点击选项
- 答对：星星爆炸庆祝动画
- 答错：温和提示，再试一次

## 5. Component Inventory

### RocketExplodedView（火箭爆炸图组件）
- 状态：assembled / exploded
- 过渡动画：500ms ease-out
- 悬停高亮效果

### LaunchSimulator（发射模拟器）
- 状态：idle / countdown / launching / stage1 / landing / complete
- 粒子系统（Canvas绘制）

### QuizCard（问答卡片）
- 状态：question / correct / incorrect
- 选项按钮带hover/active态

### InfoCard（信息卡片）
- 展开态 / 收起态
- 图标 + 标题 + 描述

### FloatingStar（浮动星星）
- 随机大小、速度、透明度
- 无限循环动画

## 6. Technical Approach

- **纯前端**：单HTML文件，内嵌CSS + JavaScript
- **动画**：CSS Animations + CSS Transitions + Canvas API
- **交互**：Vanilla JS，Event Delegation
- **字体**：Google Fonts CDN
- **无依赖**：不引入任何外部JS库（轻量快速）
