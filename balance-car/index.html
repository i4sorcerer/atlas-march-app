🎯 为什么是平衡小车

🧲

起步不难，成就感来得快

ESP32 + MPU6050 是全网资料最多的组合，第一阶段只求"站稳 30 秒"，几周内就有一个看得见摸得着的作品。

🔁

天生的迭代平台

同一台车能不断升级：加编码器、加遥控、换滤波算法、上 Web 调参面板、加避障循迹 —— 硬件不推倒重来。

🚁

飞控的地面训练场

平衡车与四轴飞控共用同一套核心：IMU 姿态解算 + 串级 PID。在地上调稳了，再上天就不慌。

🧠 主控选型：ESP32

对比三条常见路线，综合"上手难度 / 迭代空间 / 通向飞控"选择 ESP32。

🗺️ 迭代路线图 P0 → P4

P0

准备周 里程碑：板子点灯 + 读出角度 1~2 个晚上

装 Arduino IDE → ESP32 点灯 → 接 MPU6050 读原始数据，用串口绘图仪画角度曲线。

👦 儿子任务：拆快递、认零件（"这是小车的耳朵/大脑"）、给轮子装橡胶胎。
P1

站起来 里程碑：静止直立 ≥30 秒 2~4 周

装配车架 → 互补滤波求倾角 → 直立环 PD 调参（先 P 后 D，先抖再稳）。

👦 儿子任务：扶车发射员、喊 3-2-1 倒计时、掐秒表记录站立时间破纪录。
P2

动起来 里程碑：遥控行走 + 原地转圈 +2~4 周

编码器测速 → 速度环 PI 与直立环串级 → 转向环 → 手机蓝牙遥控。

👦 儿子任务：首席司机，客厅遥控绕桩。
P3

聪明起来 里程碑：抗干扰 + 自动化 +1~2 个月

一阶卡尔曼替换互补滤波并画曲线对比 → ESP32 起热点做 Web 调参面板 → 超声波避障 / 循迹。

👦 儿子任务：用积木摆障碍赛道，给小车"出考题"。
P4

通向天空 里程碑：飞控预研 长期

Mahony / Madgwick 四元数姿态解算 → 研读 ESP-Drone、Crazyflie 源码 → 下一台作品：ESP32 四轴飞行器。

👦 儿子任务：给会飞的下一台起名字。

👦 儿子 · 首席装配官 & 测试工程师

  • 拧螺丝装车架、装轮子
  • 照爸爸指的位置插杜邦线（USB 5V 低压）
  • 给小车起名、贴贴纸涂装
  • 发射倒计时、掐秒表记录"站立纪录"
  • P2 起当司机，P3 摆障碍赛道

👨 爸爸 · 首席工程师

  • 电路设计与上电前检查
  • 写代码、调 PID 参数
  • 一切带电焊接操作
  • 锂电池充放电管理
  • 每阶段拍视频存档，儿子出镜讲解
⚠️ 安全红线：锂电池充电必须有人在场；孩子不碰烙铁、剪线钳、电池本体； 所有孩子上手环节均在断电或 USB 5V 低压状态下进行。

🚁 平衡车 → 飞控 知识映射

这台车上学到的每一样东西，都能在飞控里找到对应位置。

平衡车里学到的飞控里对应的迁移程度
MPU6050 读数 + 零偏校准同类 IMU（ICM-42688 等）✅ 完全一致
互补滤波 / 卡尔曼求倾角姿态解算（Mahony / Madgwick / EKF）✅ 直接升级
直立环（角度 PD）角度环 Angle Mode✅ 同构
速度环（编码器 PI）角速度环 Rate Mode✅ 串级思想相同
两轮差速转向四电机混控 Mixer⚙️ 思想相通
PWM 驱动有刷电机DSHOT 驱动电调 + 无刷⚙️ 协议不同原理同
串口 / 蓝牙调参地面站（Betaflight Configurator）✅ 概念一致
