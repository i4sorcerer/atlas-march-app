# 🔥 祝融号小火星车（zhurong-hao）

给 **5 岁小朋友** 的祝融号火星车科普互动网站。可爱画风 + 探索风格，既有科学又有娱乐，方便后续扩展。

## 功能一览
- 🌟 **Hero 区**：星空 Canvas 背景、小车车漂浮动画、"出发"引导
- 🤖 **它是谁**：三张可爱卡片介绍名字来历、长相、中国骄傲
- 🚀 **前世今生时间线**：点小星球看祝融号一路的故事（数据驱动）
- 🔧 **拆开看看**：可交互爆炸图，点零件听它是干嘛的
- 🕹️ **开一开**：小朋友当小司机，左右开 + 挖一挖找火星秘密
- 🎈 **小问答**：4 道选择题，答对放星星庆祝
- 🌈 **尾声**：鼓励小朋友的航天梦

## 运行方式
```bash
cd zhurong-hao
npm start          # 或 node server.js
# 浏览器打开 http://localhost:3000
```
> 服务器只用 Node 内置模块，**无需 `npm install`**。

## 扩展指引
所有内容都是**数据驱动**的，改这几个数组即可加内容：
- `app.js` 里的 `MILESTONES` —— 时间线节点
- `app.js` 里的 `PARTS` —— 拆解图零件
- `app.js` 里的 `QUIZ` —— 问答题目
- `styles.css` 的 `:root` 变量 —— 配色主题

## 目录结构
