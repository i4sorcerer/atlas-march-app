# 手搓平衡小车计划 - SPEC.md

> 目标：下班后不刷短剧，带着 5 岁的儿子，用晚上的碎片时间搓出一台**真正能站稳的两轮平衡小车**，
> 并且这台车是一个可以长期迭代的平台 —— 从 PID 直立，一路升级到卡尔曼滤波、四元数姿态解算，
> 为后续研究**飞控算法**铺路。

---

## 1. 需求分析

| 诉求 | 对应设计 |
|------|----------|
| 起步不难，能做出具体的东西 | 第一阶段只求"站稳 30 秒"，用最成熟的 ESP32 + MPU6050 方案，社区资料海量 |
| 支持平衡算法 | 互补滤波 → 卡尔曼滤波 → 串级 PID（直立环+速度环+转向环），全部自己写 |
| 可持续迭代 | 硬件留扩展口（编码器、OLED、超声波、蓝牙手柄），软件分阶段升级 |
| 带 5 岁儿子一起 | 明确亲子分工：孩子做机械装配/测试/涂装，爸爸做焊接/代码/锂电 |
| 对飞控算法研究有帮助 | 平衡车与飞控共享同一套核心：IMU 姿态解算 + 串级 PID，见 §7 映射表 |

## 2. 技术方案选型

### 2.1 主控对比

| 方案 | 上手难度 | 迭代空间 | 通向飞控 | 结论 |
|------|---------|---------|---------|------|
| **ESP32**（推荐 ✅） | ★★☆ Arduino IDE 即写即刷 | WiFi/蓝牙内置，Web 调参、手机遥控零成本 | ESP-Drone 四轴同生态直接复用 | **选它** |
| STM32F103 | ★★★ 需 Keil/CubeIDE + 仿真器 | 工业主流，寄存器级学习深 | 主流飞控（匿名、正点原子）多用 STM32 | P3 之后可平移 |
| Arduino UNO | ★☆☆ 最简单 | 算力/内存吃紧，浮点慢 | 弱 | 不选 |
| micro:bit / 图形化 | ★☆☆ 孩子友好 | 算法深度不够 | 弱 | 只作孩子遥控端玩具 |

**决策：ESP32 DevKit（ESP32-WROOM-32）**。理由：便宜（¥20 级）、Arduino 生态资料最多、
自带 WiFi/蓝牙（后期做网页调参面板和手机遥控不用加任何硬件）、
与乐鑫官方开源四轴 **ESP-Drone** 同一生态，P4 阶段无缝衔接。

### 2.2 核心器件

| 部件 | 选型 | 理由 |
|------|------|------|
| IMU | MPU6050（GY-521 模块） | 平衡车/飞控最经典六轴，DMP 可选，教程最多 |
| 电机 | GA12-N20 减速电机 ×2，**带霍尔编码器**，300~500rpm | 一步到位买带编码器的，速度环必需，避免二次采购 |
| 电机驱动 | TB6612FNG | 比 L298N 效率高、发热小、体积小 |
| 电源 | 18650 ×2（串联 7.4V）+ 电池盒带开关 | 通用、便宜；充电用独立座充更安全 |
| 车架 | 亚克力两层板 + 铜柱（或 3D 打印） | 起步用现成亚克力套装，后期可自己画图打印 |
| 显示（可选） | 0.96" OLED (SSD1306, I2C) | 显示角度/PID 参数，调试利器，孩子也爱看 |
| 扩展（可选） | HC-SR04 超声波、TCRT5000 循迹、蓝牙手柄 | P3 阶段玩法扩展 |

### 2.3 软件栈

- 开发环境：Arduino IDE 2.x（起步）→ PlatformIO + VSCode（P2 以后）
- 姿态解算：互补滤波（P1）→ 一阶卡尔曼（P3）→ Mahony/Madgwick 四元数（P4）
- 控制：直立环 PD（P1）→ +速度环 PI 串级（P2）→ +转向环（P2）
- 调参：串口打印 → 蓝牙串口 APP → 自建 Web 调参面板（ESP32 起 WiFi 热点）

## 3. 阶段路线图

| 阶段 | 里程碑 | 预计投入 | 内容 |
|------|--------|---------|------|
| **P0 准备周** | 板子点灯 + 读出角度 | 1~2 个晚上 | 装 Arduino IDE，ESP32 点灯；接 MPU6050 读原始数据，串口画角度曲线。孩子：拆快递、认零件、装轮子 |
| **P1 站起来** | 静止直立 ≥30 秒 | 2~4 周（每晚 30~60 分钟） | 装车架；互补滤波求倾角；直立环 PD 调参。孩子：扶车、喊倒计时、记录站立秒数 |
| **P2 动起来** | 遥控行走 + 原地转圈 | +2~4 周 | 编码器测速，速度环 PI，串级；转向环；手机蓝牙遥控。孩子：当司机 |
| **P3 聪明起来** | 抗干扰 + 自动化 | +1~2 个月 | 一阶卡尔曼替换互补滤波并对比曲线；Web 调参面板；超声波避障 / 循迹。孩子：设置障碍赛道 |
| **P4 通向天空** | 飞控预研 | 长期 | 四元数姿态解算（Mahony/Madgwick）；研读 ESP-Drone / Crazyflie 源码；下一台：ESP32 四轴 |

**节奏建议**：每晚固定 30~60 分钟"车库时间"，周末做大节点（装配/大调参）。每个阶段结束拍一条视频存档，孩子出镜讲解。

## 6. 关键算法学习路径

1. **PID 入门**：先看 B 站 DR_CAN《PID 控制器》系列，再撸直立环（本质 = 倒立摆）
2. **互补滤波**：加速度计低通 + 陀螺仪高通，10 行代码理解传感器融合
3. **串级 PID**：直立环（内环，快）+ 速度环（外环，慢）+ 转向环，理解"环环相扣"
4. **卡尔曼滤波**：DR_CAN《卡尔曼滤波器》系列，一阶 KF 替换互补滤波，画曲线对比
5. **四元数姿态解算**：Mahony / Madgwick，从"一个倾角"到"三维姿态"，正式进入飞控领域

## 7. 平衡车 → 飞控 知识映射表

| 平衡车里学到的 | 飞控里对应的 | 迁移程度 |
|----------------|--------------|---------|
| MPU6050 读数 + 校准 | 同款/同类 IMU（ICM-42688 等） | ✅ 完全一致 |
| 互补滤波 / 卡尔曼求倾角 | 姿态解算（Mahony/Madgwick/EKF） | ✅ 直接升级 |
| 直立环（角度 PD） | 角度环（Angle Mode） | ✅ 同构 |
| 速度环（编码器 PI） | 角速度环（Rate Mode） | ✅ 串级思想相同 |
| 两轮差速转向 | 四电机混控（Mixer） | ⚙️ 思想相通 |
| PWM 驱动有刷电机 | DSHOT 驱动电调+无刷 | ⚙️ 协议不同原理同 |
| 串口/蓝牙调参 | 地面站（Betaflight Configurator） | ✅ 概念一致 |

**P4 推荐路径**：ESP-Drone（乐鑫官方，ESP32 四轴，¥200 级）→ Crazyflie 源码研读 →
Betaflight/ArduPilot 社区跟进。
