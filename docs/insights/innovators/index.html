② 趋势与规律

为什么现在挖

聚变、脑机、具身、航天、低空在中国集体进入『资本+舆论』升温期，早期创始人与『背后工程师』仍在被公开关注前夜。本期多家企业完成大额融资却尚未大众化，是提前建仓窗口。

信号源优先级

一手官方/权威媒体 > 一线投融资报道 > 论文署名与专利 > 争议性自述。技术里程碑（首飞、稳态、临床、IPO 过会）是强验证信号；纯概念叙事降权。

中国 vs 全球

中国线索集中在前沿硬科技攻坚与工程化落地；国际线索（Neuralink 5 万小时脑电预训练、SpaceX IPO）作为对比参照，标注国别与差距/领先点。

③ 研判与方向

本主题定位

不是『名人榜单』，而是『探测雷达』：提供可复用的挖掘框架 + 可持续更新的早期候选梯队，用事件（里程碑/融资/首发）持续提级或降级。

建议行动

按 5 维度每周扫描早期融资/论文/争议信号；优先把 T3 中已有硬工程证据者（如智冉医疗、箭元科技）向 T2 提级复盘；对『概念+无工程』者标注误判风险。

判定原则

名气≠价值：更看重『非共识路线 + 可验证落地时间表』。同一人可因 IPO/关键里程碑而公开化，届时退出『早期挖掘』名单，转为已确认对象。

④ 关联脉络

  • 非共识路线 → 突破性工程验证 → 资本涌入 → 进入大众视野（早期 → 知名）
