② 趋势与规律

模型：商用梯队进入「智能交互界面」阶段

GPT-6 借助 Intelligent UI 向 ToC 大规模开放，标志头部模型竞争从纯能力向「交互体验 + 成本」双维延伸；Anthropic 以 Haiku 5.5 打出成本牌、Mistral 以 1 万亿参数 + 开源权重在欧洲对标，中国 GLM-5.3 出海登陆 Bedrock 结算体系，全球模型梯队实力此消彼长加速。

Agent：从单点助手走向「协议 + 平台」标准化

Meta+Sierra 个人Agent协议、Google Gemini Agent、Salesforce×Google 深化——本窗国际动作集中在 Agent 之间/Agent 与企业系统的互操作标准与企业级治理。个人与企业场景双轨标准化推进。

资本：中美头部同步加速，算力仍为核心

OpenAI 传 300亿美元级 Pre-IPO（估值目标 1.4 万亿美元）、DeepSeek 逼近千亿人民币融资并引入腾讯/宁德时代；叠加此前 xAI 200亿美元、英伟达算力投资与中东主权基金持续入场，资本高度向头部算力与模型集中。

监管：从自律承诺走向强制性政府机制

美国参议员 AI 安全委员会法案（权重提交+发布前测试）、纽约市地方 AI 听证、韩国 4.7 万亿韩元前沿AI项目——「安全审查前置 + 国家能力投入」成为美/欧/亚多地共同方向，Agent 能力上升同步抬高治理与网络安全关注。

③ 研判与方向

主线观察一：Agent 从「演示」进入「标准化治理」关键期

个人Agent协议、Claude for Government、Gemini Agent 等动作齐发，建议重点跟踪 Agent 互操作标准（MCP 生态、Personal Agent Protocol）与安全治理的落地，这是企业规模化部署的瓶颈所在。

主线观察二：中国模型出海进入「结算体系」深水区

GLM-5.3 登陆 Bedrock、Kimi K3 上架 AWS/百炼，中国头部模型正从「能力追赶」转向「借海外云渠道商业化出海」，收入分成模式可持续性值得持续跟踪，Qwen4 是否跟进是下一个观察点。

主线观察三：算力与资本继续向中美头部聚集

OpenAI、DeepSeek 大额融资侧面反映算力军备竞赛未止；中东主权资本在 OpenAI/xAI/Anthropic/算力端的持续落子，可能重塑全球 AI 筹码分布，需关注对芯片出口与算力定价的传导。

风险提示

美国 AI 安全委员会法案若落地，将要求前沿模型发布前 45 天提交权重并接受安全测试，可能抬高头部闭源模型发布节奏与合规成本；企业 Agent 网络安全风险（如先前沙盒逃逸、DNS 越权）伴随能力上升而放大。
