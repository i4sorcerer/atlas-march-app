② 趋势与规律

① 旗舰模型进入「全球 GA + 低价推广」阶段

Gemini 4 Argon 9/30 发布、10/1 先行有限开放，10/13 起全球开放给 API、AI Studio、Antigravity 与 Pro/Ultra 订阅用户，推广价约为竞品 1/5 并延续至 11 月底。同期 DeepSeek V4.1 Flash 以 ARC-AGI-2 72.9% 亮出推理精度，但每任务成本较 V4 Flash 高约 250%——精度与成本的两条曲线正在分叉，模型选型从“谁最强”变为“单位任务成本最优”。

② Agent 落地从「聊天框」下沉到「终端与流程」

本周四条落地线并行：亚马逊广告 Amazon Ads Agent 统一搜索/全流域/展示视频音频投放；千问 AI 眼镜 N1 系列与耳夹耳机把 Personal Agent 做进硬件（5000万像素影像、全天候感知、语音办事）；OPPO×Manus 让 Find X10 首发下一代智能体；腾讯 WorkBuddy 借阶跃 Step 5 Preview 补齐深度研究与 PPT 生成。Agent 正在离开独立入口，成为既有终端与工作台的默认能力。

③ 评测基准与数据主权成为第二战场

DeepSeek V4.1 Flash 的 ARC-AGI-2 成绩、国内首个全产业链评测基准“求索4.0”（待核）、以及 MCP-Tasks 榜单上 Qwen3.5 397B 以 74.2% 领先，说明中美两边都在用可复现的基准数字替代宣传口径。MCP 已成 Agent 连接外部应用的默认协议，围绕 MCP 的攻防（COPEX 基准：25 类攻击、125 场景、9 模型 3375 次试验）同步升温。

④ 资本向头部与基础设施双极集中

软银向海湾投资者拟筹 1000 亿美元新基金、DeepSeek 二轮融资拟翻倍至约 1000 亿元、Typesafe AI 8.7 亿美元（估值 75 亿美元）、微软 Maia 300 与 NVIDIA Vera Rubin 机柜设计开放同时推进。资金同时压向模型层与算力层，而博通与英特尔 CEO 同台警告“资本已成为 AI 扩张最大约束”，供给端瓶颈并未缓解。

③ 研判与方向

全球 GA 是新的护城河

Gemini 4 Argon 两周内完成“有限开放→全球 GA→低价推广”，意味着前沿能力的窗口期已压缩到以周计。模型厂商的竞争变量从 benchmark 分数转向区域可用性、企业采购路径与单位价格。中国企业需以更快的全球化部署节奏对冲。

Agent 的落地主战场移到「存量入口」

本窗四条落地案例没有一条是新建独立 Agent 应用，全部是塞进既有入口（广告平台、AI 眼镜、手机系统、办公 WorkBuddy）。判断：2026 H2 企业 Agent 采购将优先评估“能否嵌入现有系统”，而非单点能力。MCP/A2A 互操作标准因此成为采购硬指标。

评测与安全成本开始显性化

ARC-AGI-2 成绩、求索4.0 基准、MCP 攻防研究同时出现，加上 OpenAI 录音设备事件与实验室披露的协同 Agent 攻击，评测可信度与运行安全首次成为企业采购的并列条款。拥有可审计评测与安全边界的厂商将获得溢价。

资本双极集中，腰部承压

软银 1000 亿美元、DeepSeek 约 1000 亿元、Typesafe 8.7 亿美元与微软/NVIDIA 的芯片资本开支同时推进，而博通与英特尔 CEO 警告资本是最大约束。资金在模型与算力两极聚集，缺乏清晰单位经济模型的腰部 Agent 创业公司在 2026 Q4 将面临融资断档。
