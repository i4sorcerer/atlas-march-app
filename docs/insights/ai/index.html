② 趋势与规律

① 前沿模型：多强格局成形

Meta Muse Wonder 系列（10-12）把前沿梯队从 OpenAI/Anthropic 双头拉回多强，Artificial Analysis 口径下与 Opus 5.5 差距仅 2 分；Google 内部 Carbon 持续内测，模型迭代节奏未减。价格侧 GPT-6.1 Sol 不到 Astra 一半、Haiku 5.5 成本降 75%，「同等智能更低价」成为共同叙事。

② 算力与资本：瓶颈迁移

硬件侧瓶颈已从内存/晶圆/电力迁移到资本：微软 Maia 300 自研芯片 2027 吉瓦级部署、NVIDIA 开放 Vera Rubin 设计降低整机门槛、NTT 拟投 1 万亿日元为 Anthropic 建日本数据中心；博通拟为 OpenAI 定制芯片筹资逾 500 亿美元。资本回报可见性成为下一阶段决定变量。

③ Agent 落地：从平台到用户面

国际侧 Google Gemini agent、Salesforce Agentforce、Microsoft Foundry、AWS Managed Agents 完成平台就绪；国内侧 1688 接入 Accio（1 亿买家/100 万工厂）、千问 Agent 个人办事、百度与浪潮行业矩阵进入核心业务流程。落地重心由「能不能做」转向「覆盖多少用户与流程」。

④ 技术底座：长程与评测

阿里 QwenGyre 解决数小时级长程智能体训练的 GPU 空转与轨迹冗余，训练效率 +1.78 倍、通过率 52.5%→58.5%；评测侧 MCP-Atlas、τ²-Bench、Terminal-Bench 4.0 等真实工具/长任务基准成为模型与 Agent 能力的公共标尺。

③ 研判与方向

前沿格局：重回多强，价格战已开

Meta Muse Wonder 让前沿阵营由双头变为多强，叠加 GPT-6.1 Sol 半价、Haiku 5.5 降本 75%，智能上探与单价下探同时发生。对企业意味着：模型选择权扩大、迁移成本下降，采购谈判筹码向买方倾斜；对中小团队，可自托管开源（Mistral Large 4、Hy4、Kimi K3、openPangu）首次具备接近前沿的可用性。

算力：自研芯片 + 开放架构 + 区域主权三线并进

微软 Maia 300 降低对英伟达依赖、NVIDIA 开放 Vera Rubin 设计换取生态锁定、NTT/Anthropic 合作体现主权级区域算力兴起。研判：算力竞争从「抢卡」升级为「谁来出资、谁来建、谁来运维」，亚太（日、韩、中东）将成为算力外交筹码。

Agent 落地：ROI 分化决定生死

Gartner 显示高绩效企业 81% 项目正回报、低绩效 29% 说不清回报，与 McKinsey「40% 大型组织扩展 Agent」并读可得：普及率已不是门槛，可度量的回报管理才是。建议以「持续追踪 ROI + 价值组合管理」为准入门槛，优先接入已有业务流程的 job-ready 方案（Agentforce、Gemini agent、Accio、WPS Comate）。

资本：AI 下一阶段的最大约束

博通、英特尔 CEO 同台警告资本为最大制约，博通拟为 OpenAI 定制芯片筹资逾 500 亿美元、英特尔完成约 200 亿美元增发。研判：融资成本与回报可见性将先于芯片短缺决定扩张节奏，二级市场对 AI capex 的耐心成为关键变量，需跟踪 2027 年五大云厂商 1.2 万亿美元 capex 预期的兑现度。
