本期综述

全球年发射超 230 次

截至 09-24，全球轨道发射约 228 次、成功 228、失败 7，美国约 139 次居首、中国约 69 次第二。（含亚轨道口径约 235 次）

美国靠一箭之力领跑

Falcon-9 年内约 101 次，SpaceX 连续第三年单独超过除美国外全球之和。（108 vs 106）

星舰将首飞入轨

Starship 第 14 次试飞（NET 09-28）为首次轨道任务，计划投放首批 Starlink v3 卫星。（待监管批准）

趋势与规律

  • “一箭多星 + 复用”常态化：Falcon-9 复用与可回收火箭普及，单发效率持续抬升。趋势
  • 巨型星座成为发射主引擎：Starlink 等星座批量补网，是年发射量激增的最大动因。标签
  • 新兴商业发射场开花：中国海南商业发射场、东风商业新区启用，发射基础设施加速扩容。时间线
3

研判与方向

  • 核心看点：Starship 首个轨道任务（09-28）是否如期并投放星链，将是下一代超重型运力的关键节点。关注
  • 风险信号：印度 PSLV 三级异常、空间碎片与轨道拥堵、监管审批节奏（如 FAA）构成不确定性。风险
  • 机会信号：日本 MMX 火卫一采样、印度 Gaganyaan 载人前无人试飞、中国商业火箭密集发射，均指向新一轮里程碑。利好
4

关联脉络

  • 国家机构 ⇄ 商业公司：CNSA ↔ 长征/商业火箭；NASA ↔ SpaceX；JAXA ↔ 三菱重工；ISRO ↔ NSIL。
  • 火箭 ⇄ 星座 ⇄ 应用：发射能力决定星座规模，星座又反哺通信 / 遥测 / 导航产业。
  • 发射场 ⇄ 产业链：新发射场带动区域制造、测控与人才聚落。
