② 趋势与规律

星舰：首轨落地开启‘V3组网+高频复用’新章

IFT-14 单发部署26颗星链V3（约26Tbps量级）证明星舰组网运力；IFT-15或10月发射、FAA两追加窗口暗示发射频率抬头。若IFT-15复现入轨+回收，星舰将从测试转向准运营载具，‘每10天可向月球发射一次’的月球基建叙事获得载体。

Optimus：内存策略暴露量产硬约束

马斯克为产量主动牺牲AI5/AI6内存规格，明确‘内存供给是Optimus量产独占约束’；约5000台订单+中国供应商审计指向规模化BOM落地。但V3机械手仍依赖人工组装与触觉传感器瓶颈（此前待核），‘按万下单’与‘整机瓶颈’间的兑现差是10月关键观察。

政府角色：从顾问回归到军工联合牵头

子午线计划（120天出成果）使马斯克以企业家身份Deep嵌入五角大楼未来作战研究，叠加SpaceX为金穹卫星网络主要承包商，其商业版图与国防采购深度互锁；相较America.gov的待核出席，此为新确凿的政府接口。

汽车基本盘：交付回暖但盈利仍待验证

Q3交付超预期+上海占比过半+中国9月回正，构成‘以价换量’有效信号；但财报利润下滑、储能与智能驾驶盈亏分化，股价全年仍跌。市场重心转向Q3财报毛利率、储能13.7GWh与Cybercab/FSD商业化兑现。

③ 研判与方向

星舰：首轨成功打开‘高频复用组网’估值通道

IFT-14首轨+26颗V3部署是星舰商业化的分水岭——从‘验证入轨’跨入‘可复用高频组网’阶段。IFT-15若在10月顺利、并复现入轨回收，将强化星链V3全球容量战争叙事与SpaceX 2万亿美元估值支撑；反之内审拖长则节奏回落。关注FAA公告两窗口的官方确认。

Optimus：量产叙事进入‘订单+产能’双重验证

内存下调显示马斯克以成本与供应确定性换规模化，属量产执行层务实决策；约5000台订单+中国供应商审计是BOM落地的硬信号。但V3手部/触觉瓶颈未解，‘按万下单’尚不能等同‘按万下线’。10月‘周产千台’节点与Robotaxi自用消化是兑现验证尺。

政府-军工三重绑定：本窗最显著的结构变量

子午线计划使马斯克以非官方头衔深度参与五角大楼未来作战研究，与其SpaceX金穹承包商、xAI算力、Optimus军工潜力叠加，形成‘技术-资本-防务’互锁。对SpaceX是政策接口与订单想象，对舆论是权力集中争议；需警惕监管与政治反噬对估值的影响。

投资主线：交付企稳但转向盈利质量

Q3交付超预期结束‘销量担忧’，但华尔街更关注毛利率、储能盈利与单均收入；SpaceX市值破2万亿美元为独立资本叙事。中期看，Optimus量产兑现+星舰组网+X/政府订单将共同决定马斯克系资产的定价斜率。
