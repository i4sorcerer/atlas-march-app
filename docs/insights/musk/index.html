约570万辆召回备案（9/25起实施）为近年最大规模之一：应急拉手辨识（加贴警示+OTA车窗控制）与组合驾驶辅助注意力监测（OTA新增舱内摄像头）双线；叠加Model 3/Y限时尾款立减，中国区「合规修复+以价换量」并行，10月初Q3交付数据成关键验证点。

Colossus 2现55万颗（11万GB200+44万GB300），三批各22万颗GB300于下周/11月/12月底前上线，年底约121万颗；叠加Colossus 1约23万颗，两集群约78万颗。算力承诺首次给出分批时间表，与OpenAI×英伟达直接对垒。

IFT-14维持9/28窗口（75分钟、美东8:15开窗），B21+S41完成低温加注演练；但推迟至9/28的官方理由为「等待监管批准」，首轨需FAA修改现有运营许可（增加太平洋备用着陆区），成败与许可双悬念。

召回「大到不能忽视」：中国区合规成本显性化

Optimus：产能翻倍与V3瓶颈并存，官方数据定方向

周产数百台（翻约10倍）与「机械手100+零部件人工组装、触觉传感器可靠性不足」并存；「只租不售」降低试错成本并反哺数据；9月「周产千台」节点若兑现将确认量产叙事，否则瓶颈论升级。

美欧监管对抗进入司法拉锯

美政府申请介入X上诉案、欧盟「准备好捍卫」1.2亿欧元罚款，案件政治化；叠加欧盟Blue Checks调查与英Grok深度伪造调查，X欧洲合规仍是国际化硬约束。
